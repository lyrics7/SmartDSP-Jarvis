# 🚀 JarvisHub

### An Open Harness for Canvas-Native Creative Agents

<div align="center">
  <img src="assets/jarvishub.jpg" width="92%" alt="JarvisHub">
</div>

<br>

**JarvisHub** is an open harness for **canvas-native creative agents**, designed to support
long-horizon multimodal creation in a unified visual workspace.

Instead of treating the canvas merely as an interface, JarvisHub enables agents to interact with
persistent multimodal content and coordinate complex creative workflows involving text, images,
videos, webpages, presentations, and other visual assets.

# 🧬 JarvisEvo

### Towards a Self-Evolving Photo Editing Agent with Synergistic Editor-Evaluator Optimization

<div align="center">
  <img src="assets/jarvisevo.jpg" width="92%" alt="JarvisEvo">
</div>

<br>

**JarvisEvo** explores a new generation of **self-evolving photo editing agents** capable of
continuously improving their editing behavior through synergistic interaction between an
**Editor** and an **Evaluator**.

By integrating multimodal reasoning, visual editing, evaluation, and iterative refinement,
JarvisEvo moves beyond one-shot image editing toward an agentic workflow that can analyze,
edit, evaluate, and improve its own results.

# 🤖 JarvisX-Cowork

### A Personal AI Creative Assistant for End-to-End Creative Workflows

<div align="center">
  <img src="assets/jarvisx-cowork.jpg" width="92%" alt="JarvisX-Cowork">
</div>

<br>

**JarvisX-Cowork** is a personal **AI creative assistant** designed for end-to-end creative
workflows.

It provides an agentic workspace where AI can participate throughout the creative process —
from understanding user intentions and gathering inspiration to organizing multimodal materials
and assisting with the production of final creative content.

# 🎨 JarvisArt

### Liberating Human Artistic Creativity via an Intelligent Photo Retouching Agent

<div align="center">
  <img src="assets/jarvisart.jpg" width="92%" alt="JarvisArt">
</div>

<br>

**JarvisArt** is an intelligent **photo retouching agent** designed to translate high-level
human creative intentions into professional image editing operations.

Through multimodal understanding and agentic reasoning, JarvisArt assists users in complex
photo-retouching workflows while preserving human creative control, bridging the gap between
natural-language instructions and professional visual editing.

# 🌧️ JarvisIR

### Elevating Autonomous Driving Perception with Intelligent Image Restoration

<div align="center">
  <img src="assets/jarvisir.jpg" width="92%" alt="JarvisIR">
</div>

<br>

**JarvisIR** is an intelligent **image restoration agent** designed to enhance visual perception
under challenging and degraded imaging conditions.

By leveraging intelligent restoration and multimodal reasoning, JarvisIR aims to improve the
quality and reliability of visual inputs for downstream perception systems, with particular
attention to challenging scenarios in autonomous driving.
